# Credits

**I'm Still Not a Robot** is an original, fan-made CAPTCHA parody game.
It is not affiliated with, endorsed by, or derived from any other game or website.

## Art
All illustrations (bicycles, hydrant, cones, sandwiches, socks, landscapes, the widget's robot logo, etc.)
are original SVG drawn in code in `assets/art.js`. No photographs or third-party images are used.

## Sound
All sound effects are synthesized at runtime with the Web Audio API. Spoken digits use the
browser's built-in speech synthesis. No audio files are bundled.

## Fonts
Uses the system font stack (Roboto where available). No font files are bundled.

## Third-party assets
None so far. Any public-domain / CC0 asset added to `/assets` will be listed here with its source URL and license.
