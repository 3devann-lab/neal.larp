It is not affiliated with, endorsed by, or derived from any other game or website.

## Original art
Drawn in code (no external images): the arcade minigames are drawn live on canvas in
`challenges/arcade.js`; `assets/art.js` holds
the widget's robot logo, the tiny widget copies (level 52), the toy robots (secret level S1),
the socks (level 10, which needs exact matching pairs), the blank tile and the emoji tiles.

## Sound
All sound effects are synthesized at runtime with the Web Audio API. Spoken digits use the
browser's built-in speech synthesis. No audio files are bundled.

## Fonts
Uses the system font stack (Roboto where available). No font files are bundled.
